# Terminus v0.2 — Implementation plan

**Date:** 2026-07-25  
**Status:** Active  
**Scope SoT:** `docs/plans/2026-07-25-terminus-v0.2-scope-design.md`  
**Roadmap:** `docs/plans/2026-07-25-terminus-roadmap-v0.2-v0.3.md`

---

## 0. Goals & hard constraints

**Ship:** multi-OS runtime foundation, light Git workbench, tasks board, snippets (+ optional Makefile import), optional tmux bridge.

**Never break:**

- Leaf id === PTY session id; layout ops preserve identity  
- High-frequency PTY bytes never through Zustand  
- Rust owns OS side effects; typed commands; structured `ErrorPayload`  
- Profile-validated spawn only (no free-form shell executor from UI)  
- Parameterized SQL; least-privilege capabilities  
- No imports from `legacy/` (behavior docs only)  
- No v0.3 items (SSH, AI, signing, updater, daemon-as-product)

**Gates:** `pnpm verify:v01` and `pnpm audit:rust` must stay green after each phase. Extend verify when new surfaces land.

## Phase B — Git UI (light)

### B1. Rust backend `src-tauri/src/git/`

Prefer **`git2` (libgit2)** for structured ops—not free-form `git` from the frontend.

| Command | Behavior |
|---------|----------|
| `git_status` | Branch, dirty files, staged/unstaged/untracked; ahead/behind when cheap |
| `git_diff_file` | File-level diff (worktree or staged) |
| `git_stage` / `git_unstage` | Pathspecs under project root only |
| `git_commit` | Message + author from repo config; no amend mega-UI |
| `git_branches` | Local list + current |
| `git_checkout` / `git_create_branch` | Local only |
| `git_stash_list` / `git_stash_push` / `git_stash_pop` | Basic |

**Security:**

- Resolve project path via existing project records (id → root); reject path escape  
- Capability review: no broad `fs:`/`shell:`  
- `AppError` codes: `GIT_NOT_REPO`, `GIT_OP_FAILED`, etc.

### B2. Frontend `src/features/git/`

| Piece | Detail |
|-------|--------|
| `gitStore` | Low-frequency poll (interval / focus); never on PTY path |
| `GitPanel` | Status list, stage/unstage, commit box, branch switcher, stash basic |
| Entry | Palette command + project chrome toggle |
| Types | Mirror Rust camelCase contracts in `src/lib/tauri/` |

**Done when:** open git project shows status; stage+commit works without shell hacks; remove project never touches `.git`.

**Defer:** PR/hosting UI, conflict merge editor, submodule deep tools, worktrees mega-UI.

## Phase C — Snippets

| Deliverable | Detail |
|-------------|--------|
| Storage | Project-local file e.g. `.terminus/snippets.json` (or app config dir + project key)—prefer files over layout SQLite |
| CRUD commands | list/create/update/delete |
| Insert | Write body to **focused** session via existing `write_pty` |
| Makefile import | Read-only parse targets → propose snippet drafts |
| UI | Palette + panel; no second executor |

**Done when:** insert reaches focused PTY; no spawn on insert.

| Deliverable | Detail |

## Phase E — tmux bridge (opt-in)

| Deliverable | Detail |
|-------------|--------|
| Detect | `tmux` on PATH; list sessions |
| Attach | Open as alternative session backend (document control-mode lifecycle) |
| UX | Clear local PTY vs tmux-attached labeling |
| Restart story | Document what survives app quit |
| Default | Local PTY remains default; never silent replace |

**Done when:** optional path works when tmux present; default path tests unchanged.

**Not in scope:** Terminus-owned always-on mux daemon.
